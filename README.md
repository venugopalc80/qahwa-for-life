# Qahwa For Life

A premium pre-launch café website concept for Qahwa For Life, inspired by Madinah and designed around the brand story, opening announcement and Bethnal Green location.

## Included

- Responsive landing page
- Madinah-inspired editorial visual direction
- Brand story section
- Menu preview
- Opening-soon location section
- Instagram and TikTok links
- Google Maps link
- Mobile navigation-safe responsive layout
- SEO-friendly page title and description

## Run locally

This is a static HTML/CSS site. Open `index.html` directly or deploy the repository to Vercel, Netlify, GitHub Pages, or any static host.
